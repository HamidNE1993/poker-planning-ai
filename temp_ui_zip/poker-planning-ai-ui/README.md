# Poker Planning AI UI

Starter UI Angular 22 inspiré des maquettes Poker Planning AI.

## Inclus

- Angular 22 standalone
- PrimeNG 22 + Aura
- PrimeIcons
- Design system personnalisé violet / indigo
- Sidebar + topbar
- Dashboard
- Salle de Planning Poker interactive
- Light / Dark mode
- Routes placeholders pour Sessions, Stories, Historique, Analytics et Paramètres

## Démarrage

Node.js et npm doivent être disponibles.

```bash
npm install
npm start
```

Puis ouvrir http://localhost:4200

## Intégration au monorepo

Copier ce projet dans le dossier `frontend/` du monorepo, ou reprendre `src/`, `package.json`,
`angular.json` et les fichiers TypeScript de configuration.

Le projet ne contient aucune dépendance Docker.
